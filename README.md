# Aegis AI Router

> The Operating System for Autonomous AI Agents

Aegis AI Router is a full-stack AI orchestration platform that intelligently discovers, ranks, routes, and coordinates specialized AI agents while enabling secure pay-per-use execution through x402 micropayments.

## 🚀 Features

- 🤖 Intelligent AI Agent Discovery
- 🎯 Smart Agent Ranking
- 🔄 Multi-Agent Task Routing
- 💳 Pay-per-use AI Services (x402 Payments)
- 📊 Real-time Execution Monitoring
- 📈 Analytics Dashboard
- 🔐 Secure Authentication
- 🌐 Scalable API Architecture

# ⚙️ Getting Started

## Clone Repository

```bash
git clone https://github.com/ShrutiBathe/Aegis-AI-Router.git
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```

## Backend

```bash
cd backend
python -m venv venv

# Windows
venv\Scripts\activate

# Linux/macOS
source venv/bin/activate

pip install -r requirements.txt

uvicorn app:app --reload
```
